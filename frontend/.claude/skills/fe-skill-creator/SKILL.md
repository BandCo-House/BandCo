# Fe-Skill-Creator — 프론트엔드 스킬 생성 스킬

`frontend/.claude/skills/{name}/SKILL.md`를 일관된 형식으로 작성한다.
이 스킬은 `frontend/` 범위에서만 동작한다. `backend/` 파일은 수정하지 않는다.

## 핵심 원칙

- **컨벤션은 복제하지 않는다.** 레이어·API·스타일·테스트 규칙의 단일 출처는 `AGENTS.md`다. 스킬은 표를 옮겨 적지 않고 `> 규칙 기준: AGENTS.md "{섹션}"`으로 참조한다.
- 스킬은 **절차·예시 코드·체크리스트**만 자체 보유한다.
- 모든 스킬은 `frontend/` 범위 밖을 건드리지 않는다.

## Step 1: 스킬 정보 확인

아래를 확인한다. 불명확하면 사용자에게 질문한다.

| 항목      | 규칙                                             |
| --------- | ------------------------------------------------ |
| 이름      | `fe-` 접두사 + kebab-case (예: `fe-figma`)       |
| 디렉토리  | `frontend/.claude/skills/{name}/`                |
| 파일      | 디렉토리 안에 `SKILL.md` 하나                    |
| 트리거    | 사용자가 어떤 말로 부를지 (자연어 문구 3개 이상) |
| 참조 섹션 | 이 스킬이 의존하는 `AGENTS.md` 섹션 목록         |

`name`은 frontmatter와 디렉토리명이 반드시 일치해야 한다.

## Step 2: frontmatter 작성

```markdown
---
name: fe-{name}
description: {한 줄 역할}. "{트리거 문구1}", "{트리거 문구2}", "{트리거 문구3}" 요청 시 트리거한다. {독립/조합 사용 여부와 하지 않는 일}.
---
```

`description` 규칙:

- 한국어로 쓴다.
- 트리거 문구를 따옴표로 나열한다 (스킬 자동 선택의 근거가 된다).
- 트리거하지 않는 경우나 하지 않는 일이 있으면 명시한다 (예: "구현하지 않고 검증만 한다").

## Step 3: 본문 작성

본문은 아래 골격을 따른다. 말투는 한국어 명령형(`~한다`), 구조는 표·`Step N`·예시 코드(fenced block)·체크리스트다.

```markdown
# Fe-{Name} — {역할} 스킬

{한 줄 설명}
이 스킬은 `frontend/` 범위에서만 동작한다. `backend/` 파일은 수정하지 않는다.

> 규칙 기준: `AGENTS.md` "{섹션}", "{섹션}"

## Step 1: ...

## Step 2: ...

## 자가 확인

- [ ] ...
```

작성 규칙:

| 항목      | 규칙                                                             |
| --------- | ---------------------------------------------------------------- |
| 범위 선언 | 본문 첫 문단에 frontend 범위 한정을 반드시 적는다.               |
| 경로 표기 | frontend 루트 기준 상대경로(`src/...`)를 쓴다. AGENTS.md와 동일. |
| 예시 코드 | 추상 예시보다 **실제 파일 패턴**을 인용한다 (예: `band-api.ts`). |
| 표        | 선택지·매핑·체크 항목은 산문 대신 표로 정리한다.                 |
| 자가 확인 | 마지막에 체크리스트로 결과를 스스로 검증하게 한다.               |

## Step 4: 일관성 점검

새 스킬을 기존 fe- 스킬(`fe-publish`, `fe-test`, `fe-api`, `fe-qa`)과 비교해 형식이 어긋나지 않는지 확인한다.

## Step 5: 하네스 등록

새 스킬을 만들면 `frontend/CLAUDE.md`의 "하네스: Frontend" 트리거 표와 변경 이력에 한 줄 추가한다.

## 자가 확인

- [ ] `name`이 디렉토리명과 일치하는가?
- [ ] `description`에 트리거 문구가 3개 이상 있는가?
- [ ] 본문에 frontend 범위 선언이 있는가?
- [ ] 컨벤션을 복제하지 않고 `AGENTS.md` 섹션을 참조했는가?
- [ ] 예시 코드가 실제 코드 패턴을 인용하는가?
- [ ] 자가 확인 체크리스트가 있는가?
- [ ] `frontend/CLAUDE.md` 트리거 표에 등록했는가?
