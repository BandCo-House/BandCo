# JamPlay Frontend — Claude 하네스

`frontend/src` 작업용 Claude 하네스다. **컨벤션 단일 출처는 [AGENTS.md](AGENTS.md)** — 레이어 구조·작성 규칙·API·상태/데이터·라우팅·UI/스타일·접근성·타입/schema·테스트·MSW 규칙이 모두 거기 있다. 작업 전 관련 섹션을 읽는다.

스택: Vite + React + TypeScript, TanStack Router/Query, axios, MSW, Tailwind CSS v4, shadcn/Radix UI.

## 기본 원칙

| 원칙          | 규칙                                                     |
| ------------- | -------------------------------------------------------- |
| 확인 우선     | 가정하지 말고 현재 코드·테스트·문서를 먼저 확인한다.     |
| 최소 변경     | 요청된 문제를 해결하는 데 필요한 파일과 코드만 수정한다. |
| 단순성        | 더 단순한 접근이 있으면 이유와 함께 제시한다.            |
| 설명 가능성   | 설명할 수 없는 추상화나 우회 코드를 작성하지 않는다.     |
| 안전성        | 파괴적 명령은 명시적 요청 없이 실행하지 않는다.          |
| 패키지 매니저 | `pnpm`만 사용한다.                                       |

## 검증

| 상황      | 명령                                                |
| --------- | --------------------------------------------------- |
| 타입 검증 | `pnpm --dir frontend exec tsc -b`                   |
| 포맷 확인 | `pnpm --dir frontend exec prettier --check <files>` |
| lint      | `pnpm --dir frontend run lint`                      |
| test      | `pnpm --dir frontend test`                          |

검증 실패를 무시하고 완료로 보고하지 않는다.
