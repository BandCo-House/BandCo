# JamPlay — 프로젝트 개요

## 서비스 소개

밴드 멤버들이 함께 음악을 만들고 연습할 수 있는 협업 플랫폼.

---

## 핵심 개념

```
밴드 (Band)
└── 팀 (Team)
    └── 스케줄 (Schedule)
        └── 공간 (Space) — 실제 주소를 가진 물리적 장소
```

- **밴드**를 만들고 밴드 내에 **팀**을 구성한다
- 팀 단위로 **스케줄**을 생성하고 관리한다
- **공간(Space)**은 실제 주소를 가진 물리적 장소로, 스케줄에 장소로 등록된다

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| 밴드·팀 관리 | 밴드 생성, 팀 구성, 멤버 초대·관리 |
| 스케줄 관리 | 팀 단위 일정 생성·조율, 멤버 간 스케줄 공유 |
| 연습 기록 아카이빙 | 연습 내용·기록을 누적 보관 |
| 회의 | 팀 내 회의 진행 |
| 공간 관리 | 연습실 등 물리적 공간 등록 및 스케줄 연결 |

---

## 도메인 모듈

| 모듈 | 역할 |
|------|------|
| `auth` | JWT 기반 인증 |
| `users` | 사용자 계정·프로필 |
| `bands` | 밴드 생성·관리·멤버십 |
| `spaces` | 실제 주소를 가진 물리적 공간 (스케줄 장소로 활용) |
| `songs` | 곡 관리 및 협업 |
| `skills` | 사용자 악기·기술 프로필 |
| `notifications` | 알림 |

> 스케줄·아카이빙·회의 등 추가 도메인은 개발 진행에 따라 이 문서에 추가한다.
